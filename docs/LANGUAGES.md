# "Before we begin" in the opening title (needs native-speaker checks before launch)

The opening title cycles through these. I wrote them from my own knowledge, not from a checked source, so **every line is unverified**. A wrong or clumsy greeting in front of delegates who speak that language is worse than leaving it out. Ask a native speaker, then edit the `GREET` list at the top of the cycling code in `public/app.js` (text, language name, language code; the 4th value `1` means right-to-left).
