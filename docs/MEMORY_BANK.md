# Creative Memory Bank (working document)

Purpose: the references (songs, films, styles, moments) that the welcome game and the Day 3 game can use to make a delegate think "I remember this", before the evidence arrives. **Nothing goes into the game from here until a row is complete, sourced and rights-cleared.**

## Engine (hidden, not a visible template)
Recognition → surprise → evidence → implication. Each round uses one of four shapes so the game has rhythm:

| Type | Shape |
|---|---|
| A | Memory → surprising fact → modern implication |
| B | "You probably know this" → "Did you know?" (familiar thing, unexpected scale or history) |
| C | Guess the number: story first → options → reveal → source |
| D | Two eras: then vs now → what actually changed |

The bridge to the CCA theme in every round: Africa has produced cultural value for generations, so why has turning it into economic value at scale stayed hard? (Evidence, not nostalgia.)

## Selection test (a reference must pass all three)
1. Recognisable enough to trigger memory in more than one country or generation.
2. Historically meaningful (a checkable claim, not just "old and African").
3. Connectable to the economic story (value created, captured, lost or exported).

## Where rows come from (we do not invent them)
- Thursday's test group.
- CCA organisers and their partners.
- Delegates' own answers to the optional onboarding question ("What from your country's creative past deserves to be remembered?"), read at `/admin/memories`. These are unchecked text: verify before use.
